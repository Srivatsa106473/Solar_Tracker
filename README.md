# Livint Solar Reflector Control System

## 📌 Overview

This project is a microcontroller-based solar reflector control system.

The system:

- Detects sunlight direction using LDR sensors
- Adjusts reflector position using planetary Gear motor
- Monitors temperature and humidity (DHT)
- Detects wind speed for safety positioning

No wireless communication is implemented.

---

## ☀️ Features

- Automatic light tracking
- Motor control
- Wind safety mechanism
- Environmental monitoring
- Autonomous operation

---

## 🧩 Hardware Used

- ESP32
- 2x LDR sensors
- Motor + driver
- DHT sensor
- Wind speed sensor

---

## 🚀 Upload Instructions

1. Install Arduino IDE
2. Select ESP32 board
3. Open `Livint_Solar_Full_Functionality_code.ino`
4. Upload to device
